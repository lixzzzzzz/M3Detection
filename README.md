# M3Detection Project Page

Project page for:

**M3Detection: Multi-Frame Multi-Level Feature Fusion for Multi-Modal 3-D Object Detection With Camera and 4-D Imaging Radar**  
IEEE Transactions on Intelligent Transportation Systems, 2026.

- IEEE: https://ieeexplore.ieee.org/document/11540092
- DOI: https://doi.org/10.1109/TITS.2026.3695618
- arXiv: https://arxiv.org/abs/2510.27166

The page follows the same layout and styling as the SFGFusion project page.

## Preview locally

From the repository root:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```

## GitHub Pages

Publish the repository as a GitHub Pages site from the `main` branch and `/(root)` folder. If the repository is named `M3Detection` under user `lixzzzzzz`, the expected URL is:

```text
https://lixzzzzzz.github.io/M3Detection/
```

See `PUBLISH_CN.md` for step-by-step instructions.
